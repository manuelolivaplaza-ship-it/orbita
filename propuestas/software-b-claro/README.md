# Meridiano — Taller de software

Sitio de Meridiano, un taller de producto e ingeniería en Providencia, Santiago. Next.js, TypeScript, Tailwind. Contenido en español de Chile.

Variante B clara del rubro software: luz norte de mediodía, eje cartográfico, distinta a la variante editorial de amanecer.

## Cómo verlo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Páginas

- `/` — Inicio
- `/obra` — Índice de casos
- `/obra/[slug]` — Hidrocuenca, Puelche, Ruta del Maipo, Luma
- `/oficio`
- `/taller`
- `/contacto`
- `/privacidad`
