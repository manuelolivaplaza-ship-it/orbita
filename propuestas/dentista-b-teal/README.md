# Bruma — odontología serena

Sitio de **Bruma Odontología**, clínica dental en Vitacura (Parque Bicentenario, Santiago de Chile). Next.js, Tailwind, shadcn/ui.

Paleta teal: piedra verdeagua, laguna, bruma andina.

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Las solicitudes de hora se guardan en `data/horas.json`.
