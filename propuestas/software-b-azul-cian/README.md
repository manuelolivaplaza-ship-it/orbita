# Traza — Estudio de software

Sitio de Traza, un estudio de producto e ingeniería en Ñuñoa, Santiago. Next.js, TypeScript, Tailwind. Contenido en español de Chile.

Variante B azul-cian del rubro software: la firma es el instrumento de traza (waterfall de observabilidad). Distinta a Meridiano (eje / luz norte) y a Alba (claridad editorial).

## Cómo verlo

```bash
npm install
npm run dev
```
