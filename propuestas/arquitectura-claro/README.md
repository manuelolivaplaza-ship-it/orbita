# VETA — Atelier de arquitectura

Sitio del estudio **VETA**: arquitectura de lugar, materia y luz. Sede en Palermo, Buenos Aires.

## Páginas

- `/` — Inicio
- `/obras` — Índice de obras, con filtro
- `/obras/[slug]` — Ficha de cada obra
- `/estudio` — Equipo, premios y prensa
- `/enfoque` — Principios y proceso
- `/contacto` — Formulario y datos del atelier

```bash
npm run dev
```
