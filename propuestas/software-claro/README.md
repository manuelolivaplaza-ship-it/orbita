# Alba — Estudio de software

Sitio del estudio Alba, una boutique de producto e ingeniería en Santiago. Next.js, TypeScript, Tailwind. Contenido en español de Chile.

## Cómo verlo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Páginas

- `/` — Inicio
- `/trabajo` — Casos
- `/trabajo/[slug]` — Nativa, Puerto Lumen, Clínica Alto, Cultiva
- `/servicios`
- `/estudio`
- `/contacto`
- `/privacidad`

## Build

```bash
npm run build
```
