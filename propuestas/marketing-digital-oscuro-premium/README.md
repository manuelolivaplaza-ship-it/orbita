# Obsidiana

Estudio de marketing digital. Sitio oscuro premium en Next.js.

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

| Script | Qué hace |
| --- | --- |
| `npm run dev` | Desarrollo |
| `npm run build` | Build de producción |
| `npm start` | Sirve el build |
| `npm run lint` | ESLint |

Contenido en español de Chile. Honorarios en UF. Pauta en el Business Manager del cliente.
