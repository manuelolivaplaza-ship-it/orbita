# Obsidiana

Sitio de **Obsidiana**, atelier inmobiliario de residencias de autor en Chile (Santiago, Costa Central, Lagos del Sur). Next.js, App Router, Tailwind v4. Contenido en español de Chile.

```bash
npm install
npm run dev
```

Rutas: `/` · `/propiedades` · `/propiedades/[slug]` · `/barrios` · `/estudio` · `/diario` · `/visita`
