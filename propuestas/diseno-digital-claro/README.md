# Nítida — Estudio de diseño digital

Sitio del estudio Nítida, en Ñuñoa, Santiago. Identidad, producto y sitios. Next.js, TypeScript, Tailwind. Contenido en español de Chile.

## Cómo verlo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Páginas

- `/` — Inicio
- `/trabajo` — Encargos
- `/trabajo/[slug]` — Loica, Matta 980, Atalaya, Pliego
- `/oficio` y `/oficio/[slug]`
- `/estudio` y `/estudio/[slug]`
- `/contacto`
- `/privacidad`, `/aviso-legal`

## Build

```bash
npm run build
```
