# ETER — Repuestos

Sitio de propuesta. Sala de piezas en Independencia, Santiago.

Stack: Next.js 16, React 19, Tailwind 4. Contenido en español de Chile.

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`. No hace falta API key ni base de datos: el cruce de patente y el formulario viven en el cliente y en `/api/consulta`.
