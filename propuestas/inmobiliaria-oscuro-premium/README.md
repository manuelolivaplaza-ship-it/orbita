# Meridiano

Sitio de la corredora **Meridiano** — inventario privado, dark premium, contenido en español de Chile.

```bash
npm install
npm run dev
```

Luego abra [http://localhost:3000](http://localhost:3000).

| Ruta | Página |
|---|---|
| `/` | Inicio |
| `/propiedades` | La mesa (catálogo + filtros) |
| `/propiedades/[slug]` | Ficha |
| `/territorio` | Latitudes |
| `/territorio/[slug]` | Santiago, costa, lagos, valle |
| `/estudio` | La casa |
| `/consulta` | Presentación |

Valores en UF. La dirección de un folio off-market no se publica.
