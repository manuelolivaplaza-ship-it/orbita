# Alba · Clínica veterinaria

Sitio web de **Alba**, una clínica veterinaria de alta complejidad en Palermo, Buenos Aires. Construido con Next.js, TypeScript y Tailwind CSS.

## Cómo verlo

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Páginas

- `/` — Inicio
- `/la-clinica` — La casa y el criterio
- `/servicios` y `/servicios/[slug]` — Carta de servicios
- `/equipo` — Médicos
- `/urgencias` — Guardia 24 h
- `/turnos` — Pedido de turno
- `/contacto` — Dirección, teléfono, horarios
