# Obsidiana

Club de entrenamiento privado. Vitacura, Santiago de Chile.

Sitio web oscuro premium en Next.js — piedra volcánica, cobre y silencio.

## Cómo verlo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Páginas

- `/` — Home cinematográfica
- `/el-club` — Filosofía y origen
- `/entrenamiento` — Método y ritual del día
- `/espacio` — Recinto y cómo llegar
- `/coaches` — Equipo
- `/membresia` — Planes en UF y preguntas
- `/visita` — Reserva de visita individual

## Stack

Next.js 16 · React 19 · Tailwind CSS 4 · Motion · Lenis
