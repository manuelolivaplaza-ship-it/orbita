# Cian — odontología contemporánea

Sitio de **Cian Odontología** (Vitacura, Santiago). Next.js, Tailwind, shadcn/ui.

Paleta clara azul-cian. Contenido en español de Chile.

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Las solicitudes de hora se guardan en `data/horas.json`.
