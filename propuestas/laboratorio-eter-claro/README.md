# ETER

Laboratorio clínico. Sitio web en Next.js.

## Cómo verlo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Recorrido sugerido

1. Home — manifiesto, catálogo y domicilio.
2. `/examenes` — busca TSH o vitamina D.
3. `/resultados` — entra con el RUT de demo `16.482.339-3`.
4. `/contacto` o `/domicilio` — el formulario confirma en pantalla (sin backend).

## Stack

Next.js 16 · React 19 · Tailwind CSS 4 · TypeScript
