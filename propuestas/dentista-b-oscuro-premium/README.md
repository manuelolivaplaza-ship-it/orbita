# Obsidiana — Odontología de especialista

Sitio de la clínica dental boutique **Obsidiana**, en Vitacura, Santiago. Web oscura premium: Next.js 16, React 19, Tailwind 4.

```bash
npm install
npm run dev
```

- Evaluación con scanner y presupuesto por escrito
- Carta de arancel en CLP
- Fonasa / Isapre / particular
- Agenda en `/agenda` (las solicitudes quedan en `data/agenda.json`)
