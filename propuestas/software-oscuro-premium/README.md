# OBSIDIANA

Estudio de software. Sitio oscuro premium, contenido en español de Chile.

## Cómo verlo

```bash
cd obsidiana
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Páginas

- `/` — Inicio
- `/trabajo` — Archivo de encargos
- `/trabajo/[slug]` — Caso
- `/estudio` — El estudio
- `/contacto` — Formulario y datos

## Stack

Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · Framer Motion · TypeScript
